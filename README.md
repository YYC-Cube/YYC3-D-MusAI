## 🌌 项目概述

**MusAI（缪斯智音）** 是一款面向未来的全栈智能音乐平台，名字取自 **Music（音乐）× Muse（缪斯灵感女神）× AI（人工智能）**，寓意以 AI 为灵感引擎，重塑音乐的发现、播放、创作与社交体验。

平台采用 **前端 Web + 原生移动端 + 企业级后端** 三端一体化架构，基于 **五维驱动五高架构** 理念设计：

## 🚀 快速开始

### 前置要求

- **Node.js** >= 18.0.0
- **pnpm** >= 9.0.0 (`npm install -g pnpm`)
- **MySQL** >= 8.0
- **Redis** >= 7.0 (可选但推荐)

### 1. 克隆项目

```bash
git clone <repository-url>
cd D-Music-99
```

### 2. 安装依赖

```bash
# 安装所有 workspace 依赖
pnpm install
```

### 3. 环境配置

```bash
# 后端环境变量
cp backend/.env.example backend/.env
# 编辑 backend/.env 填写数据库配置

# 前端环境变量（可选）
cp frontend/.env.example frontend/.env
```

### 4. 数据库初始化

```bash
# 创建数据库
cd backend
pnpm run migrate
```

### 5. 启动开发服务器

```bash
# 终端1：启动后端
cd backend
pnpm run dev

# 终端2：启动前端
cd frontend
pnpm run dev

# 终端3：启动移动端（可选）
cd mobile-app
pnpm run start
```

访问地址：

- 前端：`http://localhost:20101`
- 后端：`http://localhost:25101`
- API文档：`http://localhost:25101/api/health`

## 🛠️ 开发指南

### 常用命令

```bash
# 根目录命令
pnpm dev:frontend      # 启动前端开发服务器
pnpm dev:backend       # 启动后端开发服务器
pnpm build:frontend    # 构建前端
pnpm build:backend     # 构建后端
pnpm lint              # 运行所有项目的代码检查
pnpm type-check        # 运行所有项目的类型检查
pnpm test              # 运行所有项目的测试

# 前端命令（在 frontend/ 目录）
pnpm run dev           # 启动开发服务器 (port 20101)
pnpm run build         # 生产构建
pnpm run preview       # 预览生产构建 (port 20102)
pnpm run lint          # ESLint检查
pnpm run type-check    # TypeScript类型检查
pnpm run test          # 运行单元测试
pnpm run test:coverage # 运行测试并生成覆盖率报告
pnpm run analyze       # 分析构建包大小

# 后端命令（在 backend/ 目录）
pnpm run dev           # 启动开发服务器 (ts-node-dev)
pnpm run build         # 编译TypeScript
pnpm run start         # 启动生产服务器
pnpm run test          # 运行Jest测试
pnpm run migrate       # 执行数据库迁移
pnpm run migrate:undo  # 回滚最近一次迁移
pnpm run seed          # 执行数据种子

# 移动端命令（在 mobile-app/ 目录）
pnpm run start         # 启动Expo开发服务器
pnpm run android       # 运行Android
pnpm run ios           # 运行iOS
pnpm run lint          # ESLint检查
```

### 代码规范

- **TypeScript**：严格模式启用，禁止使用 `any`
- **ESLint**：前端使用 Flat Config，后端使用传统配置
- **命名规范**：
  - 组件：PascalCase (`PlayerPage.tsx`)
  - 工具函数：camelCase (`formatTime.ts`)
  - 常量：UPPER_SNAKE_CASE (`API_BASE_URL`)
- **导入顺序**：React → 第三方库 → 内部模块 → 类型导入
